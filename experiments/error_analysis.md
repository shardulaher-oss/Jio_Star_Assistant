| Category | Queries | Suggested improvement |
|---|---|---|
| wrong_document | 3 | Improve routing: index party aliases from the whole contract and abstain or ask for the agreement when two contracts tie. |
| wrong_section | 3 | Recall problem before reranking: add the clause's section heading to its embedded text, or enlarge the candidate pool. |
| ranked_too_low | 33 | The answer is retrieved but outranked: a stronger reranker or a larger rerank pool should promote it. |
| incomplete_span | 20 | Return the matched sentence plus its neighbours, or merge adjacent retrieved chunks, so long clauses are covered. |
| chunk_boundary | 5 | Chunk on clause and section boundaries rather than a fixed character budget, or add overlap only at boundaries. |
| definition_not_retrieved | 7 | Index each definition as its own passage and expand queries with defined terms they mention. |
| cross_reference | 11 | Resolve 'Section X' at indexing time, attaching the referenced text to the clause; improve heading detection so more targets resolve. |

| incorrect_abstention | 21 | Calibrate per question type, or abstain on the contract-level signal (routing) rather than a single clause score. |
| unanswerable_retrieved | 9 | Add an explicit check that the retrieved clause addresses the asked topic (e.g. a trained relevance classifier) before answering. |
